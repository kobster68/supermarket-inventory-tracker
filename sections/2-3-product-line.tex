\subsection{Product Line Reuse Considerations}
\label{sec:product-line}
\begin{notapplicable}
We design a single inventory-tracking product, not a family of separately configured
products with managed feature variation. Varying the number of stores or subscribers
is deployment and runtime variation within this product, described in
Section~\ref{sec:cc-variability}.
\end{notapplicable}
